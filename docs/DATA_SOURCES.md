# 图库来源与标注边界

本项目的图片来自纽约大都会艺术博物馆（The Metropolitan Museum of Art，简称 The Met）的官方开放接口，是本项目自行整理的中文教学图库。它包含真实藏品照片与历史绘画、版画的数字图像，不能代表现代生活场景、整个中文图文检索任务或论文标准基准。

当前版本 `met-teaching-gallery-v1` 于 2026 年 9 月 29 日整理，包含 48 张图片和 32 条中文查询。物体查询 8 条、属性查询 12 条、否定查询 12 条；验证查询与测试查询各 16 条。图片主体涵盖花瓶、杯子、椅子、鸟、船、钟表、猫和花卉题材，没有生成图片。官方英文名称中“Pap boat”等器皿不作为船的正例，花朵形首饰与戴花环的人像也不作为花卉绘画的正例。

## 许可与来源证据

- [The Met Open Access 政策](https://www.metmuseum.org/hubs/open-access)将公有领域作品的开放图片与相关数据以 CC0 提供。
- [官方 API 文档](https://metmuseum.github.io/)解释了 `isPublicDomain`、`primaryImageSmall` 和 `objectURL` 字段。图库仅采纳 `isPublicDomain=true` 且具有官方开放图片地址的记录。
- [CC0 1.0 许可文本](https://creativecommons.org/publicdomain/zero/1.0/)说明该许可的公有领域贡献方式。

`data/gallery.json` 中，每张图片都包含中文标题、人工中文描述、图片文件、藏品官网链接、`CC0-1.0` 许可及中文标签。`source_metadata` 保留获取时的完整官方 API 记录，包括对象编号、原始英文标题、媒介、开放状态、原图及缩略图下载地址。中文标题和描述用于教学检索，不是博物馆提供的官方译名，也不据此断定作者、年代、材质或文物真伪。

项目使用官方 `primaryImageSmall` 下载地址，将图像等比例缩至最长边不超过 512 像素，转换为 RGB JPEG；没有裁切主体，也没有使用生成式图像编辑。源站可以更新元信息或图片，保留的元信息反映本次整理时的状态。

## 复现与本地核验

```powershell
.\.venv\Scripts\python.exe scripts/prepare_gallery.py --check
.\.venv\Scripts\python.exe scripts/prepare_gallery.py
.\.venv\Scripts\python.exe scripts/prepare_gallery.py --refresh
```

第一条只核验本地文件和标注，不访问网络。第二条检查已有图片，并补下载缺失的图片。第三条重新访问官方对象接口，确认当前仍为公有领域且提供开放图片后重下载。网络操作最多同时进行四个请求；失败会报错，不会用生成图或占位图片替代。下载依赖 Pillow，已包含在项目依赖中。

脚本还提供 `--discover data/images/candidates.json`，用于发现候选图片。该操作只是收集官方记录和图片，输出不自动成为正式图库；加入新数据前仍须人工检查可见内容、许可证据和查询正例。

## 查询与评估边界

`data/queries.json` 保存中文查询、全部标注正例、类别和划分。类别为物体（`object`）、可见属性（`attribute`）、明确排除条件（`negative`）。否定查询使用“正向描述，不要排除描述”，只依据肉眼可见的颜色、物体和场景标注，不用模型得分挑选容易成功的查询。

`validation` 用于观察或调整启发式权重，`test` 用于固定配置后的报告。两组查询访问同一图库，所以这里的划分是查询划分，不是互不相交的训练集和测试集；多条查询可能共享正例。图库小、类别分布和图片风格有限，指标适合比较本项目的几种检索方法，不能据此推断通用模型的总体能力。

人工标注可能遗漏细小、模糊或次要物体；本集按描述中的主要可见内容定义相关性。颜色词描述图片中的外观，不能证明藏品的材质。若以后修改图库或标注，应重新运行校验、重新建向量库，并在比较结果时记录图库版本。

物体查询按画面主要主体标注，器物上的微小装饰图案不自动构成另一物体类别的正例。属性与排除条件按主体上清晰、显著的可见特征判断，不用背景颜色、黑白图片中不可推断的原始颜色或单个像素作证据。黑白照片的中文描述会明确标注图片形式。
